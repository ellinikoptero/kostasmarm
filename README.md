# kostasmarm — Personal Life Hub

A single repository to organize everything: diet, training, travel, work, university, Claude prompts/outputs, and miscellaneous notes.

## Structure

```
.
├── diet/               # Nutrition: meal plans, recipes, tracking, shopping lists
│   ├── meal-plans/
│   ├── recipes/
│   ├── tracking/
│   └── shopping-lists/
├── training/           # Fitness: programs, workout logs, progress, notes
│   ├── programs/
│   ├── logs/
│   ├── progress/
│   └── notes/
├── travel/             # Trips: planning, per-trip folders, documents
│   ├── planning/
│   ├── trips/
│   └── documents/
├── work/               # Professional: projects, CV & applications, admin, notes
│   ├── projects/
│   ├── cv-applications/
│   ├── admin/
│   └── notes/
├── university/         # Studies: courses, notes, assignments, exams, thesis
│   ├── courses/
│   ├── notes/
│   ├── assignments/
│   ├── exams/
│   └── thesis/
├── claude/             # AI workflow: prompts, skills, outputs, config
│   ├── prompts/
│   ├── skills/
│   ├── outputs/
│   └── config/
└── misc/               # Everything else: ideas, finance, archive
    ├── ideas/
    ├── finance/
    └── archive/
```

## Conventions

- **File naming:** use `YYYY-MM-DD-topic.md` for dated entries (logs, trip notes) so files sort chronologically.
- **One folder per unit:** one folder per trip, per course, per work project — keep related files together.
- **Markdown first:** prefer `.md` for notes so everything is readable directly on GitHub.
- **Archive, don't delete:** move finished/outdated material into `misc/archive/` instead of deleting it.
